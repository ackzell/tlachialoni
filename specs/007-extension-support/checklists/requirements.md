# Requirements Checklist: Extension Support

- [ ] Install from the Chrome Web Store works by pasted URL or raw ID (FR-001).
- [ ] Install from an unpacked folder copies into tool storage (FR-002).
- [ ] Invalid packages are refused with no partial install (FR-003).
- [ ] Installed extensions persist and reload at every launch (FR-004, FR-005).
- [ ] Installs and updates show a spinner, stage message, and progress bar (FR-006).
- [ ] Success auto-dismisses; errors persist until dismissed (FR-007).
- [ ] The status surface overlays without resizing the page and uses Tlapalli tokens (FR-008).
- [ ] Extensions load only into the guest session; the shell is isolated (FR-009).
- [ ] Every capability is a palette command (FR-010).
- [ ] Remove unloads before deleting files (FR-011).
- [ ] Archive paths are validated (FR-012).
- [ ] Nothing is bundled or auto-installed (FR-013).
- [ ] Changing the extension list does not disturb the current page (FR-014).
- [ ] State schema v2 sanitizes malformed extension records (FR-015).
- [ ] Constitution Principle II amendment records the exception (2.2.0).
- [ ] `vp check` and `vp test` pass.
